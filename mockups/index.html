UI 重构静态稿

三个方向，每个都是可点击的单文件原型，覆盖登录、概览、待确认、重新识别（含回收站）、处理记录、设置。数据均为示例。

V1 · 精修版

保留现有的蓝白风格与卡片语言，重整信息架构。

  • 统一左侧导航，待处理数量常驻
  • 概览首屏回答「还好吗 / 有什么等我」
  • 设置从弹层改为独立页面

V2 · 内页 Liner Notes

取材唱片内页：纸面、墨色、松绿色顶栏。

  • 标志：曲目时长条带，把识别依据画出来
  • 待确认页并排对照本地与候选的时长序列
  • 顶部标签式导航

V3 · 目录编号 Catalog

取材唱片厂牌编目：哑光黑底、白色细线、状态色码。

  • 标志：近 30 天处理节奏的山脊线图
  • 每张入库专辑一个目录编号
  • 窄图标导航，手机端变为底栏

每个原型内部的页面通过地址栏 hash 切换：#login #dash #review #recovery #records #settings
